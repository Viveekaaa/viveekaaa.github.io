Privacy policy

faceless-shorts app · last updated 12 November 2026

Who uses this app

faceless-shorts is a personal tool used only by the owner of the Tiny Whys YouTube channel, to upload that channel's own videos. It is not offered to the public.

What it accesses

With the owner's consent, the app uses Google's OAuth permission youtube.upload, which only allows uploading videos to the owner's channel. It cannot read, edit or delete existing videos, comments, subscribers or any other account data.

What it stores

It stores only the owner's own sign-in token, privately, so that scheduled uploads can run. It does not collect, store, sell or share any data about viewers or any other person.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Through the Tiny Whys channel page on YouTube.
